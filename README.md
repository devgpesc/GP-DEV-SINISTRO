# EventsCar — Gestão de Sinistros

Plataforma SaaS para gestão de sinistros automotivos (seguros, frotas e oficinas).

## Stack

- **Frontend:** React + Vite + TypeScript
- **Backend:** Vercel Serverless (`api/`)
- **Banco e auth:** Supabase

## Desenvolvimento local

1. Instale as dependências: `npm install`
2. Copie `.env.example` para `.env.local` e preencha as variáveis
3. Inicie o app: `npm run dev`

## Deploy

- **Produção:** https://eventos.escsistemas.com
- Variáveis de ambiente: veja [.env.example](.env.example)
